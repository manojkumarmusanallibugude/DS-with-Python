# BST Height, Min, and Max Operations in Python

---

## 1. Introduction

You now know how to build a BST, insert values, search for them, and delete them. But a BST can tell you much more about itself.

Three fundamental questions every BST must answer:

- **How tall am I?** — Height
- **Who is my smallest value?** — Minimum
- **Who is my largest value?** — Maximum

These sound simple. But once you understand *why* they work, you will understand recursion and tree structure at a much deeper level.

---

## 2. Real-World Motivation

**Height** tells you the performance of your BST. A BST with height 3 for 7 nodes is perfectly balanced. A BST with height 6 for 7 nodes is nearly a linked list. Databases and compilers check tree height to decide whether to rebalance.

**Minimum** is used in deletion (finding the inorder successor), in scheduling systems (find the task with the least priority), and in game engines (find the nearest enemy).

**Maximum** is used in leaderboards (the current high score), in auction systems (find the highest bid), and in operating systems (find the process that has waited the longest).

---

## 3. Key Terminology

| Term | Meaning |
|------|---------|
| **Height** | The number of edges on the longest path from root to any leaf. An empty tree has height −1. A single node has height 0. |
| **Minimum** | The leftmost node in the BST. The BST property guarantees it. |
| **Maximum** | The rightmost node in the BST. The BST property guarantees it. |
| **Balanced Tree** | Height ≈ log₂(n). Every operation is O(log n). |
| **Degenerate Tree** | Height ≈ n. Operations degrade to O(n). |

## 5. Operation 1: Height

### The Idea

The height of a tree is the length of the longest branch from the root to a leaf.

Think of it like measuring the tallest column in a building. You measure the left wing. You measure the right wing. You take whichever is taller, and add 1 for the current floor.

```
height(node) = 1 + max(height(left), height(right))
```

**Base case:** If the node is `None` (empty), its height is −1. This is the standard convention — it makes the leaf node correctly compute as height 0.

```
height(None)     = -1
height(leaf)     = 1 + max(-1, -1) = 0      ✅
height(one level above leaf) = 1 + max(0, 0) = 1  ✅
```

### Analogy

You are measuring the depth of a cave. At every fork, you send a scout down the left tunnel and a scout down the right tunnel. You wait for both to return with their measurements. You take the deeper measurement, add 1 for the current junction, and report up.

### Implementation

```python
def height(self, node=None, _first=True):
    if _first:
        node = self.root

    if node is None:        # Base case: empty tree/subtree
        return -1

    left_height  = self.height(node.left,  _first=False)
    right_height = self.height(node.right, _first=False)

    return 1 + max(left_height, right_height)
```

### Trace on a Small Tree

```
        [50]
       /    \
     [30]  [70]
     /
   [20]
```

## 6. Operation 2: Minimum

### The Idea

In a BST, the smallest value is always the **leftmost node** — the node you reach after going left as many times as possible.

Why? Because the BST property guarantees that everything to the left of any node is smaller. So the leftmost node has nothing smaller to its left. It is the minimum.

### Analogy

You are in a library arranged alphabetically. The very first book on the very first shelf (leftmost shelf, leftmost position) is the book closest to 'A'. You don't need to check any other shelf.

### Implementation

```python
def find_min(self):
    if self.root is None:
        return None             # Empty tree has no minimum

    current = self.root
    while current.left is not None:   # Keep going left
        current = current.left

    return current.data         # Leftmost node is the minimum
```

### Recursive Version (for understanding)

```python
def find_min_recursive(self, node=None, _first=True):
    if _first:
        node = self.root

    if node is None:
        return None

    if node.left is None:       # Can't go further left → this is the minimum
        return node.data

    return self.find_min_recursive(node.left, _first=False)
```

### Trace

```
         [50]
        /    \
      [30]  [70]
      /  \  /  \
    [20][40][60][80]
    /
  [10]

Start at [50] → go left to [30] → go left to [20] → go left to [10]
[10] has no left child → MINIMUM = 10  ✅
```

## 7. Operation 3: Maximum

### The Idea

Symmetrically opposite to minimum. The largest value is always the **rightmost node** — the node you reach by going right as many times as possible.

### Analogy

Same library. The very last book on the very last shelf (rightmost position) is the book closest to 'Z'. The maximum is always at the far right.

### Implementation

```python
def find_max(self):
    if self.root is None:
        return None             # Empty tree has no maximum

    current = self.root
    while current.right is not None:   # Keep going right
        current = current.right

    return current.data         # Rightmost node is the maximum
```

### Recursive Version

```python
def find_max_recursive(self, node=None, _first=True):
    if _first:
        node = self.root

    if node is None:
        return None

    if node.right is None:      # Can't go further right → this is the maximum
        return node.data

    return self.find_max_recursive(node.right, _first=False)
```

### Trace

```
         [50]
        /    \
      [30]  [70]
      /  \  /  \
    [20][40][60][80]
    /
  [10]

Start at [50] → go right to [70] → go right to [80]
[80] has no right child → MAXIMUM = 80  ✅
```

## 8.Height of Left vs Right Subtree

A balanced BST has nearly equal-height left and right subtrees. This difference is called the **Balance Factor**, and it is the foundation of AVL Trees.

```python
def balance_factor(self):
    if self.root is None:
        return 0

    left_h  = self.height(self.root.left,  _first=False)
    right_h = self.height(self.root.right, _first=False)

    return left_h - right_h    # 0 means perfectly balanced
                               # > 1 means left-heavy
                               # < -1 means right-heavy
```

| Balance Factor | Meaning |
|----------------|---------|
| 0 | Perfectly balanced |
| 1 or −1 | Acceptable (one side one level deeper) |
| > 1 | Left-heavy → may need rotation |
| < −1 | Right-heavy → may need rotation |

## 9. Complete Program

```python
class Node:
    def __init__(self, data):
        self.data  = data
        self.left  = None
        self.right = None

    def __repr__(self):
        return f"Node({self.data})"


class BST:
    def __init__(self):
        self.root = None

    # ── Insertion ────────────────────────────────────────────
    def insert(self, data):
        if self.root is None:
            self.root = Node(data)
        else:
            self._insert_recursive(self.root, data)

    def _insert_recursive(self, node, data):
        if data < node.data:
            if node.left is None:
                node.left = Node(data)
            else:
                self._insert_recursive(node.left, data)
        elif data > node.data:
            if node.right is None:
                node.right = Node(data)
            else:
                self._insert_recursive(node.right, data)

    # ── Height ───────────────────────────────────────────────
    def height(self, node=None, _first=True):
        """
        Returns the height of the tree.
        Height = number of edges on the longest root-to-leaf path.
        Empty tree → -1. Single node → 0.
        """
        if _first:
            node = self.root

        if node is None:
            return -1

        left_height  = self.height(node.left,  _first=False)
        right_height = self.height(node.right, _first=False)

        return 1 + max(left_height, right_height)

    # ── Minimum ──────────────────────────────────────────────
    def find_min(self):
        """
        Returns the minimum value in the BST.
        Always the leftmost node — iterative approach.
        """
        if self.root is None:
            return None

        current = self.root
        while current.left is not None:
            current = current.left

        return current.data

    # ── Maximum ──────────────────────────────────────────────
    def find_max(self):
        """
        Returns the maximum value in the BST.
        Always the rightmost node — iterative approach.
        """
        if self.root is None:
            return None

        current = self.root
        while current.right is not None:
            current = current.right

        return current.data

    # ── Balance Factor ───────────────────────────────────────
    def balance_factor(self):
        """
        Returns left_height - right_height.
        0 → balanced. Positive → left-heavy. Negative → right-heavy.
        """
        if self.root is None:
            return 0

        left_h  = self.height(self.root.left,  _first=False)
        right_h = self.height(self.root.right, _first=False)

        return left_h - right_h

    # ── Inorder (for verification) ───────────────────────────
    def inorder(self, node=None, _first=True):
        if _first:
            node = self.root
        if node is None:
            return
        self.inorder(node.left,  _first=False)
        print(node.data, end="  ")
        self.inorder(node.right, _first=False)


# ── Driver Code ──────────────────────────────────────────────

print("  EXAMPLE 1: Balanced BST")
print("=" * 55)

bst = BST()
for val in [50, 30, 70, 20, 40, 60, 80, 10]:
    bst.insert(val)

#          [50]
#         /    \

#     [20][40][60][80]

#   [10]
```

## 10. Time and Space Complexity

| Operation | Balanced BST | Degenerate BST | Space (call stack) |
|-----------|-------------|----------------|-------------------|
| **Height** | O(n) — must visit all nodes | O(n) | O(h) = O(log n) balanced |
| **Minimum** (iterative) | O(log n) | O(n) | O(1) |
| **Maximum** (iterative) | O(log n) | O(n) | O(1) |
| **Minimum** (recursive) | O(log n) | O(n) | O(h) |
| **Maximum** (recursive) | O(log n) | O(n) | O(h) |

**Why does Height always take O(n)?**
Computing height has no shortcut — you must visit every single node to find the deepest leaf. Even in a balanced tree, every node must be touched.

**Why do Min/Max take O(log n) in a balanced tree?**
You only ever travel down one path (all left or all right). In a balanced tree of n nodes, that path is at most log₂(n) steps long.

---

## 11. Why Height −1 for an Empty Tree?

This is a deliberate convention, not an arbitrary choice.

If we defined `height(None) = 0`, then a single leaf node would have height `1 + max(0, 0) = 1`. But a leaf should have height 0 — it is a single node with no edges below it.

By defining `height(None) = -1`, a leaf correctly computes as `1 + max(-1, -1) = 0`. The math stays clean throughout the recursion.

```
height(None)  = -1       ← convention
height(leaf)  = 0        ← 1 + max(-1, -1) = 0  ✅
height(depth 1) = 1      ← 1 + max(0, 0)   = 1  ✅
height(depth 2) = 2      ← 1 + max(1, 1)   = 2  ✅
```

## 13. Common Mistakes

**Mistake 1 — Returning 0 for empty tree in height**

```python
# Wrong: leaf nodes will compute height 1 instead of 0
if node is None:
    return 0

# Correct: empty node is -1 so leaves compute to 0
if node is None:
    return -1
```

**Mistake 2 — Not checking for empty tree in min/max**

```python
# Will raise AttributeError: 'NoneType' has no attribute 'left'
def find_min(self):
    current = self.root           # root is None if tree is empty
    while current.left is not None:   # crashes here
        current = current.left

# Correct: guard at the top
def find_min(self):
    if self.root is None:
        return None
    current = self.root
    while current.left is not None:
        current = current.left
    return current.data
```

**Mistake 3 — Confusing height with number of nodes or levels**

```
Tree:          Height = 2 (edges)
    [1]        Levels = 3 (0, 1, 2)
   /   \       Nodes  = 5
  [2]  [3]
 /  \
[4] [5]
```

Height counts **edges** on the longest path, not nodes. The number of nodes on that path is `height + 1`.

**Mistake 4 — Using height as a performance proxy without checking balance**

Height alone is not enough. A tree with 7 nodes can have height 2 (balanced) or height 6 (degenerate). Always check **balance factor** alongside height.

## 15. Summary

| Concept | Key Point |
|---------|-----------|
| `height(None) = -1` | Convention that makes leaf height = 0 work out correctly |
| `height(node) = 1 + max(left_h, right_h)` | Take the deeper branch, add 1 for current node |
| `find_min` | Follow `.left` until `None` — always iterative preferred |
| `find_max` | Follow `.right` until `None` — always iterative preferred |
| Height complexity | Always O(n) — every node must be visited |
| Min/Max complexity | O(log n) balanced, O(n) degenerate |
| Balance factor | `left_height − right_height`; ideal is 0, alarm at ±2 |
| Degenerate tree | Height = n−1 instead of log₂(n); signals a rebalancing need |

Height, minimum, and maximum are not just utility functions. They are diagnostic tools. A BST that answers these three questions quickly is a BST that is working as intended. A BST where these answers are slow is a BST that is quietly becoming a linked list.
